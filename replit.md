# Karya AI

An AI work-preflight tool that turns unclear work into a clear, actionable plan — understanding assignments, briefs, emails, and files, finding missing information, and checking the final result.

Built with React 19, TanStack Start, Vite, Tailwind CSS v4, and Radix UI.

## How to run

```sh
npm run dev
```

Serves on port 5000.

## Stack

- **Framework**: TanStack Start (React 19 + TanStack Router)
- **Styling**: Tailwind CSS v4 + Radix UI primitives
- **AI**: Vercel AI SDK (`ai` package)
- **Build**: Vite 8
